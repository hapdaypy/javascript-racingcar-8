# javascript-racingcar-precours

## 0. 문자열로 이름 입력 받기 / 정수로 시도횟수 입력받기

## 1. 문자열을 입력 받은 알파벳을 ,(쉼표)로 구분하여 새로운 배열에 저장

## 2. 시도 횟수 만큼 인원 별로 직진 여부 판별해서 직긴 횟수 기록 후 출력

## 3. 직진 거리가 저장된 배열의 인덱스 중 가장 길이가 긴 인덱스 찾기

## 4. 직진 거리가 최대 직진 거리와 같으면 출력용 배열에 저장

## 5. 출력용 배열 출력

## 예외처리

- 이름이 5글자를 넘어가는 경우
- 이름을 입력 받은 문자열에 ,(콤마)만 있을 경우
- 이름을 입력 받은 문자열에 처음과 끝에 ,(콤마)가 있을 경우
- 이름을 입력 받은 문자열에 " "(공백)이 있을 경우
- 중복되는 이름이 있을 경우
- 시도 횟수를 입력 받을 때 숫자가 아닌 경우

- 시도 횟수가 1미만인 경우
